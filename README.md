# 👨‍💼 Employee Management System (OOP Wrapper)

## 📖 Objective

The objective of this project is to develop an **Employee Management System** using the principles of **Object-Oriented Programming (OOP)** in Python. The project demonstrates how OOP concepts can be applied to organize and manage employee-related information efficiently.

The system allows users to create, manage, update, display, and remove employee records while implementing important OOP features such as **classes, objects, inheritance, encapsulation, constructor overloading, method overriding, constructors, destructors, `super()`, and `issubclass()`**. The goal is to build a simple, reusable, and maintainable application that reflects real-world software design practices.

# 🚀 OOP Concepts Implemented

## 🔹 Classes & Objects
- Employee
- Manager
- Developer

## 🔹 Encapsulation
- Private attributes (`employee_id`, `salary`)
- Getter and Setter methods

## 🔹 Inheritance
- Manager inherits Employee
- Developer inherits Employee

## 🔹 Method Overriding
- Customized `display()` method in derived classes

## 🔹 Constructor Overloading
- Multiple ways to create Employee objects using default arguments

## 🔹 Constructor & Destructor
- Initialize object data
- Destroy objects when no longer needed

## 🔹 super()
- Calls the constructor of the parent class

## 🔹 issubclass()
- Checks inheritance relationships
